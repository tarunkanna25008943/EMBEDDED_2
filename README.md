# Exp-2: Stepper Motor Using LPC1768 Processor

## AIM

To interface a stepper motor with the ARM LPC1768 processor and control its rotation using GPIO control.

## APPARATUS REQUIRED

- LPC1768
- Stepper motor
- ULN2003
- External motor power supply
- Breadboard
- Connecting wire

## PARAMETERS

- LPC1768 GPIO pins configured as outputs
- Motor operated through a suitable driver
- Appropriate motor supply voltage used
- Step sequence applied
- Delay between successive step controls
- Proper common ground between controller and driver

## OUTPUT

## RESULT

The stepper motor was successfully interfaced with the LPC1768 and its direction and speed were controlled.
